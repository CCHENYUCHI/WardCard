# 🗺️ PalabraCard 功能清單與開發 Roadmap

> **狀態圖例**：  
> - `[x]` **已完成 (Completed)**：功能已上線或已通過驗證

## 📌 版本里程碑進度條

- **Phase 1: 核心單字卡與 SRS 閉環 (v1.0.0)** ➔ `100% 完成`  
  - 核心 Web 介面、SQLite 存儲、SM-2 演算法、3D 卡片、拼字測驗、Gemini 萃取。
- **Phase 2: 多租戶認證與行動端全面擴展 (v1.1.0 - 當前進行中)** ➔ `85% 完成`  
  - JWT 多租戶用戶系統已完成，Expo Mobile App 主幹完成，字典查詞與例句點字查詢已完成。
- **Phase 3: 雲端社群、音訊深度自訂與進階 AI (v1.2.0 - 規劃中)** ➔ `0% 規劃排程中`  
  - 共享字庫、DELE 考題自動生成、離線本機發音、推播複習提醒。

### 4. Google Gemini AI 智慧賦能

| **白板/教材拍照 OCR 萃取** | Web | [x] | Web 端支援圖片上傳（上傳前壓縮），Gemini Multimodal Vision 直接辨識 |
| **萃取結果預覽勾選 / 已存在單字標示** | Web / Mobile | [x] | 萃取只回傳預覽，勾選後才存入；已在單字庫的單字預設不勾選 |
| **行動端相機直接拍照萃取** | Mobile | [x] | `expo-image-picker` 拍照或從相簿選圖辨識 |

| **D0. 學習流程修正 + S5 語境四選一** | Web | [x] | 修 Enter 送出、á/ñ 遮字比對、無例句的 S4；S5 改四選一，干擾選項從自己的單字庫挑（不用 AI） |

| **D2. S4 例句庫** | Web / Server | [📅] | 萃取時順便生成 2 句額外例句（不多一次呼叫）；舊卡片手動批次補齊（25 張 / 次，flash-lite）；S4 輪替不同例句 |
| **D3. 字典查詞** | Web / Server | [x] | 離線 Wiktionary 西英字典（變化形 → 原形）+ 自己的單字庫 + 外部字典連結；找不到中文才按「用 AI 查中文」，共用快取，一鍵加入暫存箱；每個西語字旁有 🔊 發音（名詞含冠詞） |
| **例句點字查詢 (Duolingo 式)** | Web / Server | [x] | 每日複習的例句可點字看原形、中文、用法；與 D3 共用查詞引擎；「✨ AI 解析這句」一次解析整句並共用快取，同句其他字不再花額度；點字時自動念出該字，彈窗內 🔊 可重聽 |
| **句子翻譯與講解** | Web / Server | [x] | 輸入句子 → 中英翻譯 + 1–6 個重點（文法 / 慣用語 / 用法 / 文化 / 易錯，附例句）+ 其他說法；句子可點字查詢；紀錄可搜尋 / 刪除；一句一次 flash-lite，同句跨使用者沿用 |
| **A1 字源圖鑑** | Web / Server | [x] | 約 1,000 個 A1 字的字源故事、字源鏈、英文同源字、記憶聯想、用法、例句與插圖（Claude 依 Wiktionary 事實編寫，離線、零 AI 額度）；查詞與點字顯示，翻卡後顯示；加入單字庫不需 AI |
| **字根字首瀏覽 / 自訂記憶口訣 / AI 記憶法** | Web / Server | [📅] | 見 `交接-字根字首與記憶法.md`；字源圖鑑已有 `breakdown`（構詞拆解）可沿用 |
| **D4. 答錯提示** | Web | [📅] | 本機判斷只差重音 / 陰陽性 / 字尾 / 拼字相近；判斷不出來時才提供「請 AI 解釋」（快取） |
| **D5. 每日閱讀短文** | Web | [📅] | 低優先；手動生成，一天最多 1 篇，用今天與最近複習的單字 |
| **D6. 卡片圖片（上傳）** | Web | [📅] | 上傳自己的圖片（瀏覽器壓縮 512px WebP），不做 AI 生圖 |
